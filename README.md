# Slate

A tiny link-based note page for quickly moving text between devices.

## How it works

1. Paste or type anything into the editor.
2. Press **Copy link**.
3. Open that link on another device.

The note is compressed into the URL fragment (`#...`). It is not saved in a database and no environment variables or storage services are required.

## Deploy

Import this repository into Vercel and deploy it as a standard Next.js project. No additional configuration is needed.

## Local development

```bash
npm install
npm run dev
```
